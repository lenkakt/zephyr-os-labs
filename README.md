# Zephyr OS Labs
In the repository, you will find lab Zephyr-based exercises for the Operating Systems course that practice the basics of operating systems theory.
Each lab shall last approx. 90 minutes, including the short topic introduction. 

The practical labs cover the following topics:

1. *Hello* - Introduction to the development environment - *Hello world*
2. *Kernel* - Kernel and KConfig
3. *SysCalls* - System calls
3. *Threads* - Creating and working with threads
4. *Scheduling* - Working with scheduler - types of job scheduling, performance measurement
5. *Synchro* - Job synchronization - locks, semaphores, atomic operations
6. *Memory* - Memory management, assignment and protection
7. *DeviceTree* - Device management - device trees, modifying them, device controller
8. *Filesystems* - Working with file systems 
9. *Security*
